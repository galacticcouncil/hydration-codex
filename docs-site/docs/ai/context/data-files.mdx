# AI Data Files

Structured JSON files optimized for AI agent consumption. These files are designed to be loaded programmatically by AI assistants, tools, and automated workflows.

## Quick Start

```
# Start with the manifest
GET /ai/ai-manifest.json

# Load layer index for your domain
GET /ai/runtime-index.json   # For pallet work
GET /ai/ui-index.json        # For hook work

# Find cross-layer connections
GET /ai/xref-ui-runtime.json # UI → Runtime mapping
```

## File Catalog

### Tier 0: Manifest

| File | Tokens | Purpose |
|------|--------|---------|
| [`ai-manifest.json`](/ai/ai-manifest.json) | ~500 | Index of all AI files with sizes and when to use |

### Tier 1: Layer Indexes (2-5K tokens each)

| File | Tokens | Contents |
|------|--------|----------|
| [`runtime-index.json`](/ai/runtime-index.json) | ~3K | 76 pallets with storage/call/event counts |
| [`sdk-index.json`](/ai/sdk-index.json) | ~750 | 20 packages with method counts |
| [`indexer-index.json`](/ai/indexer-index.json) | ~3K | 123 entities with field counts |
| [`ui-index.json`](/ai/ui-index.json) | ~2K | 223 hooks grouped by 14 categories |

### Tier 3: Cross-References (3-10K tokens)

| File | Tokens | Contents |
|------|--------|----------|
| [`xref-edges.json`](/ai/xref-edges.json) | ~10K | All cross-layer relationships by type |
| [`xref-ui-runtime.json`](/ai/xref-ui-runtime.json) | ~3K | 53 hooks with their runtime calls/queries |

## File Formats

### runtime-index.json

```json
{
  "palletCount": 76,
  "pallets": [
    {
      "name": "Omnipool",
      "index": 59,
      "storageCount": 7,
      "callCount": 10,
      "eventCount": 9,
      "constantCount": 2
    }
  ]
}
```

### ui-index.json

```json
{
  "hookCount": 223,
  "categories": [
    {
      "name": "liquidity",
      "count": 39,
      "hooks": ["useAddLiquidity", "useRemoveLiquidity", ...]
    }
  ]
}
```

### xref-ui-runtime.json

```json
{
  "connections": [
    {
      "hook": "useAddLiquidity",
      "category": "liquidity",
      "palletCalls": ["Omnipool.add_liquidity"],
      "palletQueries": ["Omnipool.Assets"]
    }
  ]
}
```

### xref-edges.json

```json
{
  "edgeCount": 329,
  "byType": {
    "calls": [
      { "from": "ui:hook:useStake", "to": "runtime:pallet:Staking:call:stake" }
    ],
    "queries": [
      { "from": "ui:hook:useOraclePrice", "to": "runtime:pallet:EmaOracle:storage:Oracles" }
    ],
    "handles": [
      { "from": "indexer:handler:handleOmnipoolLiquidityAdded", "to": "runtime:pallet:Omnipool:event:LiquidityAdded" }
    ]
  }
}
```

## Usage Patterns

### Find hooks for a feature

```typescript
const ui = await fetch('/ai/ui-index.json').then(r => r.json());
const liquidityHooks = ui.categories.find(c => c.name === 'liquidity').hooks;
// ["useAddLiquidity", "useRemoveLiquidity", ...]
```

### Find what a hook calls

```typescript
const xref = await fetch('/ai/xref-ui-runtime.json').then(r => r.json());
const hook = xref.connections.find(c => c.hook === 'useAddLiquidity');
// { palletCalls: ["Omnipool.add_liquidity"], palletQueries: [...] }
```

### Find all Omnipool connections

```typescript
const edges = await fetch('/ai/xref-edges.json').then(r => r.json());
const omnipoolEdges = Object.values(edges.byType)
  .flat()
  .filter(e => e.to.includes('Omnipool'));
```

## Token Budget Guidelines

| Context Size | Recommended Loading |
|--------------|---------------------|
| 8K tokens | manifest + 1 layer index |
| 16K tokens | manifest + 2 layer indexes + xref-ui-runtime |
| 32K tokens | All tier 1 + all tier 3 |
| 100K+ tokens | Full cross-references.json (378K) |
