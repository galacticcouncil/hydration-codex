# L1-runtime.md

Context file for the Hydration runtime layer (Substrate/Rust).

**Location:** `agents/contexts/L1-runtime.md` (~11KB)

## What It Contains

- **All 76 pallets** with one-line descriptions
- **Storage items** per pallet
- **Extrinsics** (callable functions)
- **Events** emitted by each pallet
- **Pallet dependencies**

## When to Load

- Working on runtime/pallet changes
- Understanding storage structure
- Tracing extrinsic calls
- Analyzing event emissions

## Key Pallets

| Pallet | Purpose |
|--------|---------|
| Omnipool | Main liquidity pool with single-sided liquidity |
| Router | Trade routing across pools |
| Stableswap | Stable asset pools (Curve-style) |
| XYK | Constant product AMM pools |
| DCA | Dollar-cost averaging schedules |
| Staking | HDX staking for governance |
| AssetRegistry | Token registration and metadata |
| OmnipoolLiquidityMining | Farming rewards for Omnipool LPs |

## Pallet Categories

### Core DeFi
- Omnipool, Router, Stableswap, XYK, LBP, OTC
