# HSM

<details>
<summary>Code Documentation</summary>

### Overview

The HSM pallet implements a stability mechanism for the Hollar stablecoin within the HydraDX ecosystem.
It provides the infrastructure to maintain Hollar's peg by managing collateral assets and
facilitating the buying and selling of Hollar against these collaterals.

The mechanism works by:
- Managing approved collateral assets for Hollar
- Handling minting and burning of Hollar through integration with the GHO ERC20 token contract
- Providing buy/sell functionality for users to exchange Hollar against collateral assets
- Executing arbitrage opportunities using flash loans to maintain price stability via offchain workers

### Interface

### Dispatchable Functions

* `add_collateral_asset` - Add a new collateral asset for Hollar.
* `remove_collateral_asset` - Remove a collateral asset from the approved list.
* `update_collateral_asset` - Update parameters for an existing collateral asset.
* `sell` - Sell Hollar in exchange for collateral, or sell collateral for Hollar.
* `buy` - Buy Hollar with collateral, or buy collateral with Hollar.
* `set_flash_minter` - Configure the flash loan contract address for arbitrage operations.
* `execute_arbitrage` - Execute arbitrage opportunity between HSM and collateral stable pool using flash loans (called by offchain worker).

## Storage (3)

### Collaterals

List of approved assets that Hollar can be purchased with This storage maps asset IDs to their collateral configuration information. Only assets in this map can be used to mint or redeem Hollar through HSM. Each collateral has specific parameters controlling its usage in the HSM mechanism.

```rust
Collaterals: Map<u32 -> {
    poolId: u32,
    purchaseFee: Permill,
    maxBuyPriceCoefficient: u128,
    buybackRate: Perbill,
    buyBackFee: Permill,
    maxInHolding: Option<u128>,
}> [Blake2_128Concat]
```

**Read by SDK:** [HsmClient.loadPools](/reference/sdk/sdk#hsmclient), [HsmPoolClient.isSupported](/reference/sdk/sdk-next#hsmpoolclient), [HsmPoolClient.loadPools](/reference/sdk/sdk-next#hsmpoolclient)

### HollarAmountReceived

Amount of Hollar bought with an asset in a single block This storage tracks how much Hollar has been bought back by HSM for each collateral asset within the current block. This is used to enforce rate limiting on Hollar redemptions. Values are reset to zero at the end of each block in on_finalize.

```rust
HollarAmountReceived: Map<u32 -> u128> [Blake2_128Concat]
```

### FlashMinter

Address of the flash loan receiver.

```rust
FlashMinter: Value<H160>
```
